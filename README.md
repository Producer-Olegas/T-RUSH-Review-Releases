# T-RUSH Review

Тестовая настольная программа для проверки текстов из Google Sheets.

## Установка на Mac

**[Скачать T-RUSH Review 0.4.2 для Mac](https://raw.githubusercontent.com/Producer-Olegas/T-RUSH-Review-Releases/main/downloads/T-RUSH-Review-0.4.2-macOS-Universal.zip)**

Поддерживаются Intel и Apple Silicon. Нужна macOS 13 Ventura или новее.
Распакуйте архив, перенесите приложение в «Программы» и откройте.

**[Инструкция и ограничения тестовой версии](TESTING-RU.txt)**

## Обновления

Начиная с 0.4.0 приложение проверяет этот канал и предлагает установить
новую версию. При наличии обновления в приложении появляется зелёная кнопка.
Ручная проверка доступна в системном меню T-RUSH Review.

Если у вас 0.3.x, установите 0.4.0 один раз вручную: в старых версиях ещё нет
механизма обновлений. Локальные правки хранятся отдельно от приложения.

Архивы обновлений и appcast подписаны отдельным ключом Ed25519.
Сборка пока не подписана Apple Developer ID и не прошла нотариальную
проверку Apple: первый запуск может потребовать отдельного разрешения macOS.

## Таблицы и правки

Вставьте ссылку на тестовую Google-таблицу во вкладке «Источник».
Поддерживаются таблицы, доступные по ссылке без входа в Google.
Правки сохраняются только на вашем компьютере; обратно в Google пока
не отправляются. В установочном архиве нет заранее загруженных таблиц.

Этот репозиторий содержит только установочные файлы, сведения об обновлениях
и инструкции. Исходников, таблиц и закрытых ключей здесь нет.

Автор: [Olegas](https://t.me/cgeventprod).

## Если в старой версии белое окно

Откройте системное меню T-RUSH Review → «Проверить обновления…»
и установите последнюю версию. Если обновление из текущей папки недоступно,
закройте приложение и перенесите его в «Программы» или скачайте новую
сборку по ссылке выше. Это исправление загрузки после скачивания.
